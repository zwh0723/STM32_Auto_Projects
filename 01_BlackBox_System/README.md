# 车载数据记录仪

## 节点角色

| 节点 | 职责 |
|---|---|
| A 板（ECU） | 采集 MPU6050 → CAN 上报 → 超阈值报警 + 写 Flash |
| B 板（Monitor） | 接收 CAN 报文 → 串口格式化输出 |

## 数据流

```
MPU6050 --I2C--> A板 --CAN 0x200--> B板 --USART--> PC(串口助手)
                    |
                    +--超阈值--> CAN 0x500 报警帧
                    +---> W25Q64 (SPI) 掉电存储
```

## 关键代码位置

- `bsp_can.c` —— CAN 初始化（位定时、滤波器、中断）
- `bsp_flash.c` —— W25Q64 扇区擦除 / 页编程 / 读取
- `main.c` —— 采集、打包、阈值判断、状态机

## 踩过的坑

1. **阈值 15000 永不触发**：MPU6050 ±2g 量程满量程 16384，
   改 3000 才可手动触发
2. **重复擦写**：缺静态锁，超阈值期间每轮都擦 Flash；加 `already_saved`
   标志 + 滞回（触发 3000 / 恢复 1000）解决
3. **存的值和触发瞬间不一致**：擦除期间 `ax` 被主循环更新，
   改为先拷贝到局部变量再写
4. **显示截断**：int16 用 2 位十六进制显示，高位丢失，改 4 位
